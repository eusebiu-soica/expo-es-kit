# native modules & config plugins — agent rules

Local Expo modules (`modules/`), config plugins (`plugins/`) and native-dependency setup for {{APP_NAME}} (Expo SDK {{EXPO_SDK}}, CNG / prebuild).

## Use

- Configure native projects through config plugins in `app.config.ts`, never by hand-editing `ios/` or `android/` (they are regenerated by `npx expo prebuild`).
- New native code = new dev client: `npx expo run:ios` / `npx expo run:android` or an EAS development build. Tell the user explicitly when a rebuild is required.
- Install native deps with `npx expo install <pkg>` so versions match SDK {{EXPO_SDK}}; check `npx expo-doctor` after.
- Local modules: Expo Modules API (`npx create-expo-module --local`), Swift/Kotlin, typed TS facade in `modules/<name>/index.ts`.
- Optional native modules are imported through the lazy safe-import wrapper so a stale dev client or Expo Go degrades gracefully instead of crashing at module scope.
- Bump `runtimeVersion` (or use the `fingerprint` policy) whenever native code changes, so OTA updates never reach an incompatible binary.
- Permissions: declare usage strings in the plugin config (`NSCameraUsageDescription`, etc.) with a clear, specific reason.

## Never

- Commit changes in `ios/` / `android/` if the project uses CNG (they are in `.gitignore` for a reason).
- `import X from 'optional-native-lib'` at module scope in shared code.
- Ship an OTA update that depends on native code the installed binary does not have.
- Use `patch-package` as a permanent fix without a comment linking the upstream issue and the version to drop it at.
- Request permissions at startup; ask in context, right before the feature needs it.
- Add a native dependency for something the JS side or an existing Expo module already does.

## Patterns

```ts
// app.config.ts — plugin with options
plugins: [
  ['expo-camera', { cameraPermission: 'Allow {{APP_NAME}} to scan receipts.' }],
  './plugins/with-android-network-security',
],
```

```ts
// guarded optional import
import { lazyNativeModule } from '@/lib/safe-native-import';
const haptics = lazyNativeModule(() => require('expo-haptics') as typeof import('expo-haptics'));
export const tap = () => haptics.get()?.selectionAsync().catch(() => {});
```

```txt
# patches/<pkg>+<version>.patch — header in PR / commit:
# Why: <bug>  Upstream: <issue URL>  Remove when: <pkg> >= <version>
```
